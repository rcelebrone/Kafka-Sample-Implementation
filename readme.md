# Exemplos de Implementação do Kafka em Diferentes Linguagens

Este repositório contém exemplos de implementação de produtores e consumidores Kafka em diferentes linguagens de programação, utilizando o tópico `mms.order` e o evento `mms.order.created`.

## Tecnologias

Os exemplos abrangem as seguintes tecnologias:

*   **Python:** [`kafka.py`](kafka.py)
*   **Node.js com NestJS:** [`kafka.js`](kafka.js)
*   **Go:** [`kafka.go`](kafka.go)
*   **PHP:** [`kafka.php`](kafka.php)

## Pré-requisitos

Certifique-se de ter o Kafka instalado e em execução em sua máquina. Para instalar o Kafka, você pode seguir as instruções em [https://kafka.apache.org/quickstart](https://kafka.apache.org/quickstart).

Além disso, você precisará ter as seguintes dependências instaladas para cada linguagem:

*   **Python:** `kafka-python`
*   **Node.js:** `@nestjs/microservices`
*   **Go:** `segmentio/kafka-go`
*   **PHP:** `rdkafka`

## Como executar os exemplos

1.  Clone este repositório:

    ```bash
    git clone [https://github.com/seu-usuario/seu-repositorio.git](https://www.google.com/search?q=https://github.com/seu-usuario/seu-repositorio.git)
    ```

2.  Navegue até o diretório do repositório:

    ```bash
    cd seu-repositorio
    ```

3.  Siga as instruções específicas de cada linguagem para instalar as dependências e executar os exemplos.
